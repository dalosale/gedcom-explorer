Полное руководство по GEDCOM файлам

1. Что такое GEDCOM файл?

Аббревиатура GEDCOM расшифровывается как GEnealogical Data COMmunication. Это текстовый формат файла (обычно с расширением .ged), разработанный для обмена данными между различными генеалогическими программами. Думайте о нём как о "PDF" для генеалогии: он гарантирует, что ваше генеалогическое древо можно будет прочитать в любом ПО — Ancestry, MyHeritage, Family Tree Maker или Gramps.

2. Как экспортировать ваше генеалогическое древо

Чтобы использовать этот просмотрщик, сначала нужно экспортировать ваши данные. Вот краткое руководство для основных платформ:

  • Ancestry.com: Перейдите на вкладку "Древа", выберите ваше древо, нажмите "Настройки древа" и найдите кнопку "Экспорт древа" справа.
  • MyHeritage: Перейдите в "Генеалогическое древо" > "Управление древами". Нажмите "Экспорт в GEDCOM" рядом с древом, которое хотите загрузить.
  • FamilySearch: FamilySearch не позволяет напрямую экспортировать всю ветку одним нажатием. Вам потребуется стороннее ПО (например, RootsMagic или Ancestral Quest), чтобы синхронизироваться с FamilySearch и затем экспортировать GEDCOM файл оттуда.

3. Почему важна клиентская приватность

Генеалогические данные часто содержат конфиденциальную информацию о живых родственниках (даты рождения, девичьи фамилии, места). Большинство онлайн-просмотрщиков требуют загрузить файл на их сервер. Это создаёт риск: если их сервер взломают, данные вашей семьи будут раскрыты.

GEDCOM Explorer работает иначе. Мы используем технологию "Offline-First". Когда вы нажимаете "Открыть файл", ваш браузер считывает файл прямо с жёсткого диска вашего компьютера в свою временную память (ОЗУ). Данные никогда не передаются через интернет в наше облако. Они остаются на вашем устройстве. Как только вы закроете эту вкладку, данные мгновенно удаляются из памяти браузера.

4. Понимание структуры GEDCOM

Стандартный GEDCOM файл имеет иерархическую структуру. Он состоит из записей, связанных уникальными идентификаторами. Самые распространённые записи — INDI (Индивид) и FAM (Семья). Запись INDI содержит имя человека, пол, события рождения (BIRT) и смерти (DEAT). Запись FAM связывает мужа (HUSB), жену (WIFE) и детей (CHIL). Наш просмотрщик анализирует эти текстовые строки и визуализирует их в интерактивную диаграмму, которую вы видите выше.

5. Автосохранение данных

Ваше древо сохраняется автоматически! После загрузки GEDCOM файла все данные сохраняются в localStorage вашего браузера. При следующем посещении сайта древо загрузится автоматически — вам не нужно будет загружать файл снова. Данные остаются только на вашем устройстве и никуда не передаются.

Часто задаваемые вопросы (FAQ)

Что такое .GED файл?
GEDCOM — это международный стандарт для обмена генеалогическими данными. Вы можете экспортировать его из Ancestry, MyHeritage или FamilySearch.

Сервис бесплатный?
Да, GEDCOM Explorer полностью бесплатен.

Могу ли я редактировать моё древо здесь?
В настоящее время это просмотрщик только для чтения. Он предназначен для консультации, анализа и отображения древа, но не для редактирования данных или добавления новых людей. Для редактирования мы рекомендуем использовать ПО, в котором вы создали исходный файл.

Сохраняется ли моё древо?
Да! После загрузки файла данные автоматически сохраняются в вашем браузере. При повторном визите древо загрузится само. Вы также можете нажать "Очистить данные", чтобы удалить сохранённое древо.
